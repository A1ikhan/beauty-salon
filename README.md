# Lumière — салон красоты: лендинг + CRM

Демо-проект на React + Vite с мокап-данными. Бэкенда нет: данные хранятся в браузере (localStorage).

## Запуск

```bash
npm install
npm run dev
```

- `/#/` — лендинг (услуги и цены, мастера, отзывы, онлайн-запись)
- `/#/crm` — CRM для администратора

## Что есть в CRM

- **Дашборд** — выручка за 30 дней, средний чек, новые клиенты, отмены, график выручки по дням и по направлениям, расписание на сегодня, загрузка мастеров, дни рождения клиентов.
- **Записи** — календарь на день (колонки — мастера, клик по пустой ячейке создаёт запись) и список с фильтрами; смена статуса, проверка занятости мастера.
- **Клиенты** — поиск, фильтр по тегам, сортировка, карточка клиента с историей визитов, суммой, любимым мастером и заметками.
- **Мастера** — выручка, визиты, клиенты и будущие записи по каждому мастеру.
- **Услуги** — прайс с продажами и выручкой.

Заявка с лендинга сразу появляется в CRM со статусом «Новая». Кнопка «Сбросить демо-данные» в меню CRM возвращает исходные данные.

## Структура

```
src/data/mock.js      мокап-данные (салон, услуги, мастера, клиенты, записи)
src/store/Store.jsx   общее состояние + сохранение в localStorage
src/landing/          лендинг
src/crm/              страницы CRM
```

Название, адрес, телефон и валюта задаются в `SALON` в `src/data/mock.js`.
